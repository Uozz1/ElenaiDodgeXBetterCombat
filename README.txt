The goal of this mod is to provide enhanced mechanics when using **Better Combat** together with **Elenai Dodge 2**.

     **Features**

*   **Disables rolling** during the recovery phase of an attack.
*   **Disables attacking** while dodging.
*   **Special Attack:** If you press attack and dodge in the same frame, you trigger a special attack allowing you to attack even while dodging.
*   Customizable number of feathers players spawn with.

**You can find the configuration file as:**  
**`edxbt-common.toml`** in your Minecraft's `config` folder.
